## Presentation
Ce projet est une boite a outils commerciale developpee en Python.
Il permet de realiser plusieurs calculs utiles pour une entreprise.

## Fonctionnalites

- marge.py : calcul de la marge commerciale.
- tva.py : calcul de la TVA et du prix TTC.
- interets.py : calcul des interets simples et composes.
- ventes.py : calcul du chiffre d'affaires.

## Technologies utilisees
- Python
- Git
- GitHub

## Objectif
Faciliter certains calculs commerciaux et financiers.
